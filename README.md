# Daily UI Challenge

A collection of front-end practice builds, each recreating a UI design brief from a PDF spec, using plain HTML and CSS.

## Structure

Each challenge lives in its own numbered folder:

```
Challenge001/
  Challenge #001.pdf   # design brief
  index.html
  styles.css
  assets/img/logo.png

Challenge002/
  Challenge #002.pdf   # design brief
  index.html
  styles.css
```

## Tech Stack

- HTML5
- CSS3

No build tooling — each challenge is a static page that can be opened directly in a browser.

## Running a challenge

```bash
open Challenge001/index.html
```

(or serve the folder with any static file server, e.g. `python3 -m http.server`)

## Adding a new challenge

Create a new `ChallengeNNN/` folder containing the brief, `index.html`, and `styles.css`, following the pattern of the existing challenges.
